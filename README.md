## Deep Learning Projects

### Projects

**Faster R-CNN Object Detection on PASCAL VOC 2007**  
Detects multiple objects in images using the Faster R-CNN model trained on the PASCAL VOC 2007 dataset. Outputs bounding boxes and class labels for each detected object.

**Image Classification on CIFAR-10 using PyTorch**  
Builds a Convolutional Neural Network (CNN) to classify images into 10 different categories from the CIFAR-10 dataset.

**Image Classification on FashionMNIST using PyTorch**  
Classifies grayscale images of fashion items (e.g., shirts, shoes) using a neural network trained on the FashionMNIST dataset.

**Image Generation using Autoencoder (MNIST)**  
Uses an autoencoder model to reconstruct and generate handwritten digit images from the MNIST dataset.

**Image Segmentation using U-Net (SMP)**  
Implements the U-Net architecture using segmentation models for pixel-wise image segmentation tasks.

**YOLOv8 Object Detection (Wind Turbine & Cable Tower Detection)**  
Applies YOLOv8 for real-time object detection, specifically trained to identify wind turbines and cable towers in images.

**Fine-Tuning ResNet18 for Flower Image Classification**  
Uses transfer learning by fine-tuning a pre-trained ResNet18 model to classify different types of flower images.

**Image Search using EfficientNetV2**  
Develops an image similarity system using EfficientNetV2 to extract features and retrieve similar images based on visual similarity.

**Smoking Classifier using EfficientNetB0**  
Classifies whether a person is smoking or not using image data and a pre-trained EfficientNetB0 model.
